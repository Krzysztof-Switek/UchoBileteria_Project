{% comment %} "Wstecz" button behaviour, shared by every staff shell (admin, base_app, base_terminal). Came from another page of the app → history.back(), so you land exactly where you were (filters, scroll). Opened directly / in a new tab → follow the link, which is set to the last link of the path (one level up). The button's data-nav-back holds the CSS selector of the path links. {% endcomment %}
